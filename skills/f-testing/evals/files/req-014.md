# REQ-014: Create profile

**ID**: REQ-014
**Status**: approved
**Source**: profile form
**Created**: 2026-10-01
**Updated**: 2026-10-01

## Intent

A signed-in user can store one profile name.

## Acceptance Criteria

### AC-1: Reject empty name

**Given** a signed-in user and an empty profile form
**When** the user submits an empty name
**Then** the form shows the text "Name is required" and the profile store has no new row
**Check**: the response or DOM contains "Name is required" and the profile store has no new row
**Must not**: create a profile row

### AC-2: Store a non-empty name

**Given** a signed-in user and an empty profile form
**When** the user submits the name "Ada"
**Then** the profile store has one row for "Ada" and the response includes an id
**Check**: response field id is present and the store has one row for "Ada"
**Must not**: store a second row for the same user
